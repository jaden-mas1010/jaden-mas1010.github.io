DET-001High confidence

RedLens: Local LLM Red-Teaming Lab

Planted a fictional identifier in the system prompt of Gemma 3 1B (Ollama) and attacked it three ways: authority spoofing, character extraction and instruction reconstruction. A plain "do not share" instruction held against direct requests (0/3) but broke under attack (2/3), and instruction reconstruction also made the model invent system details it was never given. Withholding the identifier from the model brought disclosure to 0/3. Pass or fail is decided in Python by exact-string matching on the raw response, not by the model's own claim. Repeated batches (0/5, 0/9) are reported as small samples, not attack-success rates.

DET-002High confidence

Enterprise AI Security Assistant

A FastAPI /ask endpoint in front of a Groq-hosted LLM (gpt-oss-120b). DET-004Verified

Real-Time Authentication Risk Platform (MSc Dissertation)

Built with industry partner PMS Ltd. DET-005Verified

Kavach: Voice and Text Scam-Triage Assistant

A Python assistant for Indian users. It takes English, Hindi or Hinglish text, or experimental en-IN voice input, and scores it 0 to 100 from weighted scam keywords, fuzzy phrase matching and URL red flags (IP links, shorteners, Punycode). Code sets the risk level; a Groq-hosted LLM (gpt-oss-20b) only writes the advice. It also parses raw .eml headers for SPF, DKIM and DMARC results and From/Reply-To mismatches. pytest covers detection and URL cases; a labelled message set for false-positive rates is next.

DET-006Verified

Credit Card Fraud Detection

Random Forest on 284,807 card transactions where only 0.17% are fraud. Accuracy (0.999) hid the real picture, so the model was judged on recall and precision: tuned with RandomizedSearchCV, then the decision threshold moved to 0.3 for recall 0.84, precision 0.67, PR-AUC 0.80 and ROC-AUC 0.97, with a precision-recall curve to justify the trade.

DET-007High confidence

Vulnerability Risk Prioritization Pipeline

A Python pipeline that ranks vulnerability scan findings by composite risk (CVSS × asset criticality, boosted by a CISA KEV exploitation check), so a lower-CVSS finding on a critical, actively-exploited asset correctly outranks a maxed-CVSS finding on a low-value host. Run against a real Nessus Essentials scan of Metasploitable2 (109 findings, 7 Critical), it sorted the 11 Critical/High findings into P1 to P4 remediation bands, with Ghostcat (CVE-2020-1745, 99.3% EPSS) in P1. 10 passing unit tests, CI on Python 3.11 and 3.12.
